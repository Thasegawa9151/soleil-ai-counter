# Soleil AI Counter

Reinventing the web counter for the AI era.

Soleil AI Counter (SAC) is an experimental WordPress project that visualizes AI bot visits and explores AI Reachability for the modern web.

## Why

Old web culture had simple access counters:

> "You are visitor #10000"

As the web evolved into SEO, Analytics, and advertising ecosystems, that warmth gradually disappeared.

Now, in the AI era, AI agents have become invisible intermediate readers of the web.

SAC is an experiment to make those invisible visitors visible again.

## Current Experiments

- AI bot detection
- Claude fetch compatibility
- AI Reachability for WordPress
- llms.txt / robots.txt behavior
- WordPress theme compatibility
- AI-friendly web structures

## Discoveries

- Static HTML and WordPress pages behave differently for AI fetches
- Modal CTA systems can block AI accessibility
- AI visibility may become part of future website health diagnostics

## Philosophy

SAC is not built to fight AI.

It is built to welcome AI as a new kind of reader.

## Status

Experimental / Research Phase  
Currently developed as a mu-plugin and evolving through real-world testing.
